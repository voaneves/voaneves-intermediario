## What's already done well

The site is not starting from zero — it is a recently rebuilt v4. Strengths confirmed in source:

- **Critical CSS inlined** in `<head>` (hero, marquee, font-face) so first paint doesn't wait on the 75 KB external stylesheet, which itself loads non-blocking via the `preload → onload → rel=stylesheet` pattern with a `<noscript>` fallback.
- **All JS is `async`/`defer`** (six small files, ~47 KB minified total — only `playful.min.js` at 33 KB is sizeable).
- **Every `<img>` has explicit `width`/`height`** → no image-driven layout shift (CLS).
- **LCP image** (`main_1.webp`, 20 KB) carries `fetchpriority="high"`.
- **Strong SEO base**: canonical, meta description, `robots.txt`, `sitemap.xml`, Open Graph + Twitter cards, and Organization JSON-LD.
- **PWA**: manifest, service worker, full icon set, theme-color for light/dark.
- **Accessibility scaffolding**: skip link, `aria-label`s throughout, drawer with `role="dialog"`/`aria-modal`, `prefers-reduced-motion` handling, viewport allows zoom (`user-scalable=yes`).

## Findings, by Lighthouse category

### Performance

| # | Finding | Evidence | Fix |
|---|---------|----------|-----|
| P1 | **LCP image not preloaded.** `fetchpriority=high` helps, but the request still waits for HTML parse. | `main_1.webp` referenced inline only | Add `<link rel="preload" as="image" href="assets/img/main_1.webp" fetchpriority="high">` in `<head>`. |
| P2 | **Fraunces served from Google Fonts.** Extra DNS + TLS to `fonts.gstatic.com` on the critical path (~100–150 ms). | `<link href="fonts.googleapis.com/css2?family=Fraunces...">` | Self-host one variable-font axis (~70 KB woff2), `font-display:swap`, drop the two `preconnect`s. |
| P3 | **`no-cache` meta tags.** `Pragma`, `Cache-Control: no-cache`, `Expires: 0` as `http-equiv` signal "don't cache" intent and can hurt repeat-view scoring. | `<head>` http-equiv tags | Remove them; set real caching via GitHub Pages / a CDN with long `max-age` + hashed asset names. |
| P4 | **`playful.min.js` is 33 KB and drives 14 motion systems.** Main-thread cost = Total Blocking Time risk. | `assets/js/playful.min.js` | Cut motion paradigms to ≤5 (see plan UX-2); tree-shake the rest. Target TBT < 150 ms. |
| P5 | **Service worker precache is minimal** (`"/"` only) and the cache version is `v1`. | `worker.js` | Precache the core route + hashed CSS/JS/LCP image; bump cache name on each deploy so stale assets invalidate. |

### Accessibility

| # | Finding | Evidence | Fix |
|---|---------|----------|-----|
| A1 | **Touch targets below 44 px.** Theme/translate nav buttons are ~38×38. | `to-do.md` 5.2, nav buttons | Bump utility buttons to ≥44×44. |
| A2 | **Checkbox-hack accordion** for the 8 services. Functional with `aria-label`, but not announced as expandable to screen readers. | `type=checkbox` toggles in `.bento` | Move to `<button aria-expanded>` + `<details>`/`disclosure` pattern, or add `role`/`aria-controls`. |
| A3 | **Custom drag-scroll timeline** — verify keyboard operability and visible focus on each card; native scroll fallback. | `.timeline__track[data-drag-scroll]` | Ensure cards are focusable, arrow-key scrollable, focus ring visible. |
| A4 | **Contrast edge cases** — `signal red` on `ink` (CTA hover) and red-on-cream need measuring at AA (4.5:1). | `--signal` usage | Verify; darken the light-mode red (`#c41a1a`) where it sits on cream. |

### Best Practices

| # | Finding | Evidence | Fix |
|---|---------|----------|-----|
| B1 | **Weak CSP.** `default-src * 'unsafe-inline' 'unsafe-eval'` is effectively open and is flagged by Lighthouse. | CSP meta in `<head>` | Tighten to a real allowlist; drop `'unsafe-eval'`; move inline JS to hashed/nonce'd or external files. |
| B2 | **`console.log` left in production** (`app`, `console`, `playful`, `sw`). Not score-fatal, but noise. | min JS files | Strip logs in the minify step. |
